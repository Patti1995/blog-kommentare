# Kommentare für mein-smarthome.blog

Dieses Repository speichert die Kommentare von [mein-smarthome.blog](https://mein-smarthome.blog) über [giscus](https://giscus.app).
Jeder Artikel bekommt automatisch eine eigene Diskussion unter „Announcements“, sobald der erste Kommentar geschrieben wird.

Bitte kommentiert direkt unter den Artikeln auf der Website.
